ІНСТРУКЦІЯ: НАВЧАННЯ ПУЛЬТА RC5/RC5X
====================================

Модуль: input/ir_rc5
Поки UI не написаний, навчання запускається тимчасовим кодом у main.cpp
(розділ 3). Коли зʼявиться UI, він викликає ті самі функції IrRc5.


1. ПІДГОТОВКА
-------------
- Пульт має передавати RC5 або RC5X (Philips та сумісні).
- VS1838B підключений до піна pins::kIrIn.
- У config/ir_config.h увімкнено IR_DEBUG (за замовчуванням 1),
  щоб бачити кроки навчання в Serial.
- Serial Monitor на швидкості defaults::kSerialBaud.
- Мапа кодів порожня, доки її не навчено. Навчена мапа зберігається в NVS
  (namespace "audioctl", ключ "ir_map") і переживає перезавантаження.


2. ПЕРЕВІРКА ПРИЙОМУ ДО НАВЧАННЯ
--------------------------------
Натисни будь-яку кнопку пульта. У Serial має зʼявитися:

    [IR] addr=0 cmd=16 toggle=1 rc5x=0

Це означає, що пульт прийнято й декодовано. Невідомі коди подій не
створюють, тільки цей рядок.

Якщо рядків немає:
- Перевір підключення й живлення VS1838B.
- Перевір, що пульт саме RC5 (не NEC, не Sony).
- Якщо лічильник IrRc5::decodeErrors() росте, а кадрів немає, спробуй:
    а) kMarkLevel в ir_config.h (0 = LOW це несуча, для VS1838B так і є);
    б) збільшити kHalfBitTolerancePercent (максимум 32);
    в) підібрати kMarkBiasUs (наприклад 50..100 мкс).


3. ТИМЧАСОВИЙ КОД НАВЧАННЯ В main.cpp
-------------------------------------
Додай цей блок у main.cpp ПЕРЕД функцією setup() (поза #if INPUT_DEMO_PRINT_EVENTS):

    // ---- ТИМЧАСОВО: навчання пульта (видалити, коли зʼявиться UI) ----
    struct LearnItem {
        Action action;
        const char* name;
    };
    static const LearnItem kLearnList[] = {
        {Action::POWER, "POWER"},
        {Action::UP, "UP"},
        {Action::DOWN, "DOWN"},
        {Action::LEFT, "LEFT"},
        {Action::RIGHT, "RIGHT"},
        {Action::VOL_UP, "VOL_UP"},
        {Action::VOL_DOWN, "VOL_DOWN"},
        {Action::MUTE, "MUTE"},
        {Action::MENU, "MENU"},
        {Action::INPUT_RADIO, "INPUT_RADIO"},
        {Action::INPUT_TV, "INPUT_TV"},
        {Action::INPUT_PC, "INPUT_PC"},
        {Action::INPUT_AUX, "INPUT_AUX"},
        {Action::DIGIT_0, "DIGIT_0"},
        {Action::DIGIT_1, "DIGIT_1"},
        {Action::DIGIT_2, "DIGIT_2"},
        {Action::DIGIT_3, "DIGIT_3"},
        {Action::DIGIT_4, "DIGIT_4"},
        {Action::DIGIT_5, "DIGIT_5"},
        {Action::DIGIT_6, "DIGIT_6"},
        {Action::DIGIT_7, "DIGIT_7"},
        {Action::DIGIT_8, "DIGIT_8"},
        {Action::DIGIT_9, "DIGIT_9"},
        {Action::BASS_UP, "BASS_UP"},
        {Action::BASS_DOWN, "BASS_DOWN"},
        {Action::TREBLE_UP, "TREBLE_UP"},
        {Action::TREBLE_DOWN, "TREBLE_DOWN"},
        {Action::BALANCE_UP, "BALANCE_UP"},
        {Action::BALANCE_DOWN, "BALANCE_DOWN"},
        {Action::GAIN_UP, "GAIN_UP"},
        {Action::GAIN_DOWN, "GAIN_DOWN"},
    };
    static size_t s_learnIdx = 0;
    static bool s_learnStarted = false;

    static void learnDemoTick() {
        const size_t total = sizeof(kLearnList) / sizeof(kLearnList[0]);
        if (s_learnIdx >= total) return;

        // Команди з Serial: s = пропустити дію, y = перезаписати, n = не перезаписувати.
        int ch = -1;
        if (Serial.available()) ch = Serial.read();

        if (!s_learnStarted) {
            if (IrRc5::beginLearn(kLearnList[s_learnIdx].action)) {
                Serial.printf("[LEARN] (%u/%u) press remote button for %s twice\n",
                              static_cast<unsigned>(s_learnIdx + 1),
                              static_cast<unsigned>(total), kLearnList[s_learnIdx].name);
                s_learnStarted = true;
            } else {
                Serial.println("[LEARN] cannot start (map full?), skipping");
                ++s_learnIdx;
            }
            return;
        }

        switch (IrRc5::status()) {
            case IrRc5::LearnStatus::Success:
                Serial.printf("[LEARN] %s learned\n", kLearnList[s_learnIdx].name);
                ++s_learnIdx;
                s_learnStarted = false;
                if (s_learnIdx >= total) Serial.println("[LEARN] all done");
                break;
            case IrRc5::LearnStatus::Timeout:
                Serial.println("[LEARN] timeout, retrying (send 's' to skip)");
                s_learnStarted = false;  // повторити ту саму дію
                break;
            case IrRc5::LearnStatus::Conflict: {
                Action other;
                if (IrRc5::learnConflictWith(other) && ch < 0) {
                    Serial.println("[LEARN] code already used by another action: send 'y' to overwrite, 'n' to cancel");
                }
                if (ch == 'y') {
                    IrRc5::confirmOverwrite();
                } else if (ch == 'n') {
                    IrRc5::cancelLearn();
                    s_learnStarted = false;  // спробувати ту саму дію ще раз
                }
                break;
            }
            default:  // Waiting / Confirm / Idle
                if (ch == 's') {
                    IrRc5::cancelLearn();
                    ++s_learnIdx;
                    s_learnStarted = false;
                    Serial.println("[LEARN] skipped");
                }
                break;
        }
    }
    // ---- кінець тимчасового блоку ----

Потім на початку loop() додай виклик:

    void loop() {
        learnDemoTick();   // ТИМЧАСОВО
        ...

Примітка: loop() чекає подію до 1 секунди, тож крок навчання може
реагувати з затримкою до 1 с. Це нормально.

Скорочений варіант: щоб навчити лише одну дію, замість блоку вище додай
в setup() після IrRc5::begin() один рядок:

    IrRc5::beginLearn(Action::VOL_UP);

Тоді стан можна дивитися за логами [IR] (див. розділ 4).


4. ПЕРЕБІГ НАВЧАННЯ
-------------------
Для кожної дії:

1) Прошивка пише "[LEARN] ... press remote button for VOL_UP twice".
   Запускається таймер 8 секунд (kLearnTimeoutMs).

2) Натисни потрібну кнопку пульта ОДИН РАЗ і відпусти.
   Serial:
       [IR] addr=0 cmd=16 toggle=0 rc5x=0
       [IR] learn: candidate addr=0 cmd=16, press again to confirm

3) Натисни ТУ САМУ кнопку ще раз (окреме натискання, не утримання).
   Serial:
       [IR] addr=0 cmd=16 toggle=1 rc5x=0
       [IR] map saved, entries=1
       [IR] learn: OK VOL_UP -> addr=0 cmd=16
       [LEARN] VOL_UP learned

4) Далі автоматично починається наступна дія зі списку.

Важливо:
- Утримання кнопки за одне натискання не рахується. Для підтвердження
  потрібні два окремі натискання з паузою (перший кадр серії й далі
  повтори зі зміною toggle не рахуються як друге натискання).
- Якщо між двома натисканнями натиснути іншу кнопку, вона стане новим
  кандидатом, і її теж треба буде підтвердити повторно. Так зашумлений
  одиночний кадр не потрапляє в мапу.
- Під час навчання кнопки пульта не керують пристроєм: усі кадри
  йдуть лише в логіку навчання.
- Після успішного навчання дії її попередній код замінюється новим
  (одна дія = один код після навчання).


5. КОНФЛІКТ КОДІВ
-----------------
Якщо код уже привʼязаний до іншої дії, після другого натискання буде:

    [IR] learn: CONFLICT addr=0 cmd=16 already bound to VOL_UP
    [LEARN] code already used by another action: send 'y' to overwrite, 'n' to cancel

Що робити:
- Надішли у Serial Monitor 'y': код перепризначиться на нову дію, а стара
  дія втратить цей код (запис видаляється). Serial:
      [IR] learn: overwrite confirmed
      [IR] map saved, entries=...
      [IR] learn: OK MUTE -> addr=0 cmd=16
- Надішли 'n': перепризначення скасовано, дію буде запропоновано ще раз.
  Натисни іншу кнопку пульта.
- Якщо нічого не робити 15 секунд (kLearnConflictTimeoutMs): "learn: timeout".

У майбутньому UI те саме робить виклик IrRc5::confirmOverwrite() або
IrRc5::cancelLearn(). З якою дією конфлікт, можна дізнатися через
IrRc5::learnConflictWith().


6. ТАЙМАУТ
----------
Якщо натискання немає 8 секунд (окремо для першого й другого):

    [IR] learn: timeout
    [LEARN] timeout, retrying (send 's' to skip)

Дія повторюється. Надішли 's', щоб пропустити її.


7. ПЕРЕВІРКА РЕЗУЛЬТАТУ
-----------------------
Після навчання натисни кнопки пульта. У Serial, якщо в main.cpp увімкнено
INPUT_DEMO_PRINT_EVENTS:

    [IR] addr=0 cmd=16 toggle=0 rc5x=0
    [MAIN] event: IR VOL_UP repeat=0 long=0 delta=0

Утримання VOL_UP, VOL_DOWN, UP, DOWN, LEFT, RIGHT: після ~0,5 с
(kRepeatDelayMs) йдуть події з repeat=1 приблизно кожні 114 мс.
Для решти дій приходить лише перша подія натискання.

Перезавантаж плату: у логу старту має бути
    [IR] map loaded, entries=N
Це означає, що мапа збереглася в NVS.


8. СКИДАННЯ І ЗМІНА МАПИ
------------------------
- Навчити дію наново: просто запусти навчання для неї ще раз.
- Видалити код дії: IrRc5::removeAction(Action::...).
- Очистити всю мапу (RAM і NVS): IrRc5::clearMap().
  Для одноразового очищення тимчасово додай цей виклик у setup()
  після IrRc5::begin(), прошій плату, а потім прибери його.
- Якщо дані в NVS пошкоджені або формат змінився, при старті буде
  "[IR] WARN: stored map rejected (...), map empty", і мапу треба навчити знову.


9. ПІСЛЯ НАВЧАННЯ
-----------------
Видали тимчасовий блок (розділ 3) і виклик learnDemoTick() з main.cpp.
Мапа лишається в NVS. Коли буде UI, режим навчання запускатиметься з меню
викликом IrRc5::beginLearn(action), а прогрес UI читатиме через
IrRc5::status(), IrRc5::learnTarget(), IrRc5::learnCandidate().


10. ТИПОВІ ПРОБЛЕМИ
-------------------
- Нічого не реагує, кадрів у Serial немає: розділ 2.
- Кадри є, але навчання не підтверджується: друге натискання має бути
  окремим (відпусти кнопку й натисни знову) і тією самою кнопкою.
- Кнопка іноді не розпізнається: далекий кут пульта або слабка батарея.
  Несуча 36 кГц при приймачі на 38 кГц дає нижчу чутливість. Підійди
  ближче й спробуй збільшити допуск (розділ 2).
- Подій IR немає після навчання, але [IR] рядки є: код не в мапі. Перевір,
  що навчання закінчилось "learn: OK", а не таймаутом чи конфліктом.
